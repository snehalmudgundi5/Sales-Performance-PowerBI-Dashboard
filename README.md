# 📌 Project Overview

This project is an end-to-end Business Intelligence solution developed using **SQL Server** and **Power BI**.

The objective of the project is to transform raw CRM and ERP data into meaningful business insights through a structured **SQL Data Warehouse** and an interactive **Power BI dashboard**.

The dashboard enables stakeholders to monitor business performance, analyze customer behavior, evaluate product performance, and make data-driven decisions.
